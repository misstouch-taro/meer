# Privacy Policy — meer

_Last updated: 2026-05-23_

## English

### Data collected by the developer
meer does **not** collect, transmit, or store any personal data on servers operated by the developer.
This includes analytics, telemetry, crash reports, user content, and device identifiers.

### Data stored locally
All data remains on your computer under `%AppData%\meer\`:

| Data | Purpose |
|---|---|
| Personal Access Token (PAT) | Encrypted with Windows DPAPI (safeStorage) |
| App preferences (theme, language, last-used provider/owner) | Saved as JSON; never transmitted |

Uninstalling the app removes all locally stored data.

### Third-party API access
When you browse a repository, meer sends API requests directly to the provider you have chosen (GitHub or GitLab). The developer has no visibility into, or control over, the data exchanged between your computer and those services. Please do not use meer to browse repositories whose contents are confidential.

- [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
- [GitLab Privacy Policy](https://about.gitlab.com/privacy/)

### Microsoft Store
If you installed meer through the Microsoft Store, Microsoft may collect standard install/usage telemetry per their own privacy statement, independently of this app.

### Children
meer is not directed to children under the age of 13 and does not knowingly collect data from them.

### Contact
Questions or concerns? Please open an issue on the GitHub repository.

## 日本語

### 開発者によるデータ収集
meer は、開発者が運営するサーバーに対して個人データの収集・送信・保存を**一切行いません**。
分析情報、テレメトリ、クラッシュレポート、ユーザーコンテンツ、端末識別子はいずれも対象外です。

### ローカルへの保存
すべてのデータはお使いのコンピューター上の `%AppData%\meer\` に保存されます。

| データ | 用途 |
|---|---|
| Personal Access Token (PAT) | Windows DPAPI（safeStorage）で暗号化して保存 |
| アプリ設定（テーマ、言語、最後に使用したプロバイダー・オーナー） | JSON として保存。外部送信なし |

アプリをアンインストールすると、ローカルに保存されたすべてのデータが削除されます。

### サードパーティ API へのアクセス
リポジトリを参照する際、meer は選択したプロバイダー（GitHub または GitLab）に対して直接 API リクエストを送信します。開発者はお使いのコンピューターとそれらサービス間でやり取りされるデータを閲覧したり制御したりすることはできません。機密性の高いリポジトリの参照にはご注意ください。

### Microsoft Store
Microsoft Store からインストールした場合、Microsoft が独自のプライバシーポリシーに基づいて標準的なインストール・使用状況のテレメトリを収集することがあります。これは本アプリとは独立したものです。

### 子どもについて
meer は 13 歳未満の子どもを対象としておらず、意図的にデータを収集することもありません。

### お問い合わせ
ご質問は GitHub リポジトリの Issue からお願いします。

## Español

### Datos recopilados por el desarrollador
meer **no** recopila, transmite ni almacena datos personales en servidores operados por el desarrollador.
Esto incluye análisis, telemetría, informes de errores, contenido del usuario e identificadores del dispositivo.

### Datos almacenados localmente
Todos los datos permanecen en tu equipo en `%AppData%\meer\`:

| Datos | Propósito |
|---|---|
| Personal Access Token (PAT) | Cifrado con Windows DPAPI (safeStorage) |
| Preferencias de la aplicación (tema, idioma, último proveedor/propietario usado) | Guardado como JSON; nunca se transmite |

Al desinstalar la aplicación se eliminan todos los datos almacenados localmente.

### Acceso a APIs de terceros
Cuando navegas por un repositorio, meer envía solicitudes a la API directamente al proveedor que hayas elegido (GitHub o GitLab). El desarrollador no tiene visibilidad ni control sobre los datos intercambiados entre tu equipo y esos servicios. Por favor, no uses meer para navegar por repositorios cuyo contenido sea confidencial.

- [Política de privacidad de GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
- [Política de privacidad de GitLab](https://about.gitlab.com/privacy/)

### Microsoft Store
Si instalaste meer a través de Microsoft Store, Microsoft puede recopilar telemetría estándar de instalación/uso según su propia declaración de privacidad, de forma independiente a esta aplicación.

### Menores
meer no está dirigida a menores de 13 años y no recopila intencionadamente datos de ellos.

### Contacto
¿Tienes preguntas o inquietudes? Abre un issue en el repositorio de GitHub.
