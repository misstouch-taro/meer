## English

**meer** is a frameless desktop GitHub / GitLab repository browser for Windows.
Browse public and private repositories, preview files, and download what you need — all from a clean, keyboard-friendly UI.

### Features

- **GitHub & GitLab** — supports GitHub.com, GitHub Enterprise, GitLab.com, and self-hosted GitLab
- **Public & private repos** — works without a token (public, 60 req/h) or with a PAT (private + 5,000 req/h)
- **File tree** — browse files in the root of any branch; multi-select with Click / Ctrl+Click / Shift+Click
- **File preview** — text, Markdown (with source toggle), and images
- **Download** — save individual files, folders, or the entire branch as a ZIP
- **Right-click menu** — Download / Open from context menu
- **Double-click / Enter** — open file with the OS default application
- **Search / filter** — type to filter the file list instantly
- **Light & Dark mode** — follows your Windows theme or set manually
- **Multilingual UI** — English / 日本語 / Español
- **Rate-limit badge** — remaining API requests shown in the status bar
- **Frameless window** — custom title bar; min / max / close controls

### Installation

Install from the **Microsoft Store** (recommended) or download the installer from [Releases](../../releases).

### Quick start

1. Launch meer.
2. Select a provider (**GitHub** or **GitLab**).
3. _(Optional)_ Open Settings, paste a Personal Access Token, and click **Save**.
   - GitHub token scope: `repo`
   - GitLab token scope: `read_api`
4. Enter a username or org name and click **Connect**.
5. Pick a **Repository** and a **Branch**.
6. Browse, preview, and download files.

### Privacy

meer does **not** collect any telemetry or user data. Your PAT is encrypted locally with Windows DPAPI and never transmitted to the developer. See [PRIVACY.md](PRIVACY.md) for details.

## 日本語

**meer** は Windows 向けのフレームレスデスクトップ GitHub / GitLab リポジトリブラウザです。
公開・プライベートリポジトリの参照、ファイルプレビュー、必要なファイルのダウンロードが、すっきりとしたキーボードフレンドリーな UI で行えます。

### 主な機能

- **GitHub & GitLab** — GitHub.com、GitHub Enterprise、GitLab.com、セルフホスト GitLab に対応
- **公開・プライベート リポジトリ** — トークンなし（公開、60 req/h）または PAT 設定（プライベート + 5,000 req/h）
- **ファイルツリー** — 任意のブランチのルートのファイルを参照、Click / Ctrl+Click / Shift+Click で複数選択
- **ファイルプレビュー** — テキスト、Markdown（ソース表示切替）、画像
- **ダウンロード** — 個別ファイル、フォルダ、またはブランチ全体を ZIP で保存
- **右クリックメニュー** — Download / Open
- **ダブルクリック / Enter** — OS の標準アプリで開く
- **検索・フィルタ** — 入力するだけでファイルリストを絞り込み
- **ライト・ダークモード** — Windows のテーマに自動追従または手動設定
- **多言語 UI** — English / 日本語 / Español
- **レート制限バッジ** — 残り API リクエスト数をステータスバーに表示
- **フレームレスウィンドウ** — カスタムタイトルバー、min / max / close ボタン

### インストール

**Microsoft Store**（推奨）または [Releases](../../releases) からインストーラをダウンロード。

### クイックスタート

1. meer を起動
2. プロバイダ（**GitHub** または **GitLab**）を選択
3. _(任意)_ Settings から Personal Access Token を貼り付けて **Save**
   - GitHub トークンの権限: `repo`
   - GitLab トークンの権限: `read_api`
4. ユーザー名または組織名を入力して **Connect**
5. **Repository** と **Branch** を選択
6. 参照・プレビュー・ダウンロード

### プライバシー

meer はテレメトリやユーザーデータを **一切収集しません**。PAT は Windows DPAPI でローカル暗号化され、開発者には送信されません。詳細は [PRIVACY.md](PRIVACY.md) をご覧ください。

## Español

**meer** es un navegador de repositorios GitHub / GitLab de escritorio sin marco para Windows.
Explora repositorios públicos y privados, previsualiza archivos y descarga lo que necesites — todo desde una interfaz limpia y amigable con el teclado.

### Características

- **GitHub y GitLab** — compatible con GitHub.com, GitHub Enterprise, GitLab.com y GitLab autoalojado
- **Repositorios públicos y privados** — funciona sin token (público, 60 req/h) o con PAT (privado + 5,000 req/h)
- **Árbol de archivos** — explora los archivos en la raíz de cualquier rama; selección múltiple con Click / Ctrl+Click / Shift+Click
- **Vista previa de archivos** — texto, Markdown (con alternancia a vista de código fuente) e imágenes
- **Descarga** — guarda archivos individuales, carpetas o la rama completa como ZIP
- **Menú contextual** — Descargar / Abrir desde el clic derecho
- **Doble clic / Enter** — abre el archivo con la aplicación predeterminada del sistema
- **Búsqueda / filtro** — escribe para filtrar la lista de archivos al instante
- **Modo claro y oscuro** — sigue el tema de Windows o configúralo manualmente
- **Interfaz multilingüe** — English / 日本語 / Español
- **Indicador de límite de tasa** — solicitudes API restantes mostradas en la barra de estado
- **Ventana sin marco** — barra de título personalizada; controles min / max / cerrar

### Instalación

Instala desde **Microsoft Store** (recomendado) o descarga el instalador desde [Releases](../../releases).

### Inicio rápido

1. Inicia meer.
2. Selecciona un proveedor (**GitHub** o **GitLab**).
3. _(Opcional)_ Abre la configuración, pega un Personal Access Token y haz clic en **Guardar**.
   - Alcance del token de GitHub: `repo`
   - Alcance del token de GitLab: `read_api`
4. Introduce un nombre de usuario u organización y haz clic en **Conectar**.
5. Elige un **Repositorio** y una **Rama**.
6. Explora, previsualiza y descarga archivos.

### Privacidad

meer **no** recopila telemetría ni datos del usuario. Tu PAT se cifra localmente con Windows DPAPI y nunca se transmite al desarrollador. Consulta [PRIVACY.md](PRIVACY.md) para más detalles.
