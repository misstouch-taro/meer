## en-US

### Name
meer

### Short description (≤ 100 characters)
Browse GitHub & GitLab repositories, preview files, and download — fast and keyboard-friendly.

### Description
meer is a lightweight, frameless desktop app for browsing GitHub and GitLab repositories on Windows. Whether you need to quickly preview a file, download a folder, or explore a branch without cloning, meer gives you a clean, fast UI to get it done.

**What you can do:**
- Browse public repositories without signing in
- Connect with a Personal Access Token (PAT) to access private repositories and get a higher API rate limit (5,000 req/h vs. 60 req/h)
- Navigate the file tree, preview text files and Markdown with a toggle for source view, and view images
- Select multiple files with Click / Ctrl+Click / Shift+Click
- Download individual files, entire folders, or the full branch as a ZIP archive
- Drag selected files directly from meer into Windows Explorer
- Open files with the OS default application (double-click or Enter)
- Filter the file list instantly by typing
- Supports GitHub.com, GitHub Enterprise, GitLab.com, and self-hosted GitLab

**Designed for developers:**
- Frameless window with custom title bar
- Light and Dark mode
- Multilingual UI: English, 日本語, Español
- Keyboard-friendly multi-select and navigation
- Rate-limit badge in the status bar

**Privacy-first:**
Your PAT is encrypted locally using Windows DPAPI. meer never sends your data to the developer — no telemetry, no analytics.

### Keywords
GitHub, GitLab, repository browser, file preview, developer tool, git, source code

## ja-JP

### 名前
meer

### 簡単な説明（100文字以内）
GitHub・GitLab のリポジトリをブラウズ、ファイルをプレビュー＆ダウンロード。軽快なデスクトップアプリ。

### 説明
meer は Windows 向けの軽量フレームレスデスクトップアプリで、GitHub や GitLab のリポジトリをかんたんに参照できます。クローンせずにファイルを素早く確認したい、フォルダをダウンロードしたい、ブランチを手軽に閲覧したい — そんなニーズに応えるすっきりとした UI です。

**できること:**
- サインインなしで公開リポジトリを参照
- Personal Access Token（PAT）を設定してプライベートリポジトリにアクセス、APIレート制限を緩和（60回 → 5,000回 / 時間）
- ファイルツリーの操作、テキスト・Markdownのプレビュー（ソース表示の切り替え可）、画像のプレビュー
- Click / Ctrl+Click / Shift+Click による複数ファイル選択
- ファイル・フォルダの個別ダウンロード、またはブランチ全体をZIPとして保存
- meer からWindows エクスプローラーへのドラッグ＆ドロップ
- ダブルクリックまたは Enter でOSの標準アプリで開く
- 入力するだけでファイルリストをリアルタイムに絞り込み
- GitHub.com、GitHub Enterprise、GitLab.com、セルフホスト GitLab に対応

**開発者のために設計:**
- カスタムタイトルバーのフレームレスウィンドウ
- ライト / ダークモード
- 多言語対応 UI：English、日本語、Español
- キーボードに対応した複数選択とナビゲーション
- ステータスバーのレート制限バッジ

**プライバシー重視:**
PAT は Windows DPAPI でローカル暗号化されます。テレメトリ・分析情報の送信は一切ありません。

### キーワード
GitHub, GitLab, リポジトリブラウザ, ファイルプレビュー, 開発ツール, git, ソースコード
